# Creative Studio

A responsive recreation of the supplied illustrated city website, with editable HTML billboard content.

Run `npm run dev`, then open http://localhost:4173.

No dependencies or build step. Generated image originals are retained in `assets/`; asset briefs are in `assets/README.md`. Navigation focuses the page panels; project cards open artwork previews; the enquiry dialog offers an email link. The email address comes from the reference and should be replaced before production use. Social links display an honest unconfigured state.

Build for production with `npm run build`. Upload the contents of `dist/` to any static host. Run `npm run preview` to view the production build at http://localhost:4174.
